プライバシーポリシー

運営：Opelog（屋号・個人事業主）　／　制定日：2026年6月5日　／　改定日：2026年10月24日

Opelog（以下「当方」）は、当方が提供するアプリ「KartePaste」（以下「本アプリ」）における利用者の情報を、以下のとおり取り扱います。

1. 基本方針（処理モードの選択）

本アプリでは、初回起動時に、利用規約と本ポリシーへの同意のあと、処理モードを選んでいただきます。音声の文字起こし・文章の整形を端末内で行うか、外部のサービスに送信して行うか、またその送信先は、選んだモードによって決まります（下記2のとおり）。録音、文字起こし、整形結果などのデータは、原則として利用者の端末内に保存されます。当方は、下記2の中継を除き、これらの内容を取得・閲覧しません。

2. 処理モードと送信先

外部のサービスで処理するモード（以下「クラウドのモード」）では、当方が運営する中継サーバー（Cloudflare Workers）を経由して処理します。モードごとの送信先は次のとおりです。

  • 医療従事者モード（医療情報など重要な情報を扱う方に推奨）：音声の文字起こし・テキストの整形をいずれも、Google LLC が運営する Vertex AI の東京リージョン（日本国内のデータセンター）で処理します。
  • 一般モード（高速・高性能）：音声の文字起こしを Groq, Inc.（米国）、テキストの整形を Google の Gemini（米国を含む国外で処理される場合があります） で処理します。速度・品質を優先する設定です。
  • 無料モード（オフライン）：音声の文字起こし（Whisper）・テキストの整形（Qwen3.5）をいずれも端末内で行い、録音・文章の内容を外部に送信しません（初回のみ、処理に使うモデルのダウンロードが必要です）。
  • カスタム：文字起こし（Vertex AI 東京／Groq／端末内の Whisper／端末内のリアルタイム文字起こし）と整形（Vertex AI 東京／Gemini／端末内の Qwen3.5）を個別に選びます。送信先は、選んだ組み合わせに応じて上記のとおりです。

モードを選ぶ前の初期設定は、医療従事者モードと同じ送信先（Vertex AI 東京リージョン）です。

中継サーバーは、API キーを安全に管理するための中継のみを行い、送受信内容を保存・記録（ログ）しません。クラウドのモードは、サブスクリプションの契約中、またはお試しパック（下記7）の残りがある間に利用できます。モードは設定からいつでも変更でき、無料モードを選べば外部に送信しません。国外（米国）へ送信されるモード・組み合わせ（一般モード、カスタムで Groq または Gemini を選ぶ場合）を初めて選ぶときは、送信先と国外へ転送されることを表示し、同意を確認します（初回起動時のモード選択で一般モードを選んだ場合は、その選択をもって同意とします）。医療従事者モードは、初回起動時の利用規約・本ポリシーへの同意をもって利用できます。送信先サービスを変更・追加する場合は本ポリシーを更新します。

3. 外国（国外）への移転

医療従事者モードを利用する場合、音声・テキストとも、Google LLC（米国）が運営する Vertex AI の東京リージョン（日本国内のデータセンター）で処理されます（中継の Cloudflare はグローバルネットワークですが、内容を保存しません）。一般モード（高速・高性能）（カスタムで Groq または Gemini を選ぶ場合を含む）を利用する場合、音声（Groq・米国）およびテキスト（Gemini・国外を含む）が日本国外で処理されることがあります（個人情報の越境移転に該当し得ます）。移転先国の個人情報保護制度および安全管理措置に関する情報は、お問い合わせ窓口へのご請求に応じて提供します。

医療従事者モードの処理場所は、日本国内のデータセンター（Google LLC が運営する Vertex AI の東京リージョン）です。医療情報の取扱いについては、厚生労働省「医療情報システムの安全管理に関するガイドライン」および総務省・経済産業省「医療情報を取り扱う情報システム・サービスの提供事業者における安全管理ガイドライン」（いわゆる3省2ガイドライン）があります。本アプリは医療機器ではなく、当方は同ガイドラインへの適合を保証するものではありません。医療機関等での利用の可否や、どのモードを使うかは、各機関の規程・体制に従ってご判断ください。

4. 取得・取り扱う情報

  • 本アプリ内で作成・保存されるデータ（録音・文字起こし・整形結果・メモ等）：原則として端末内に保存
  • クラウドのモードで外部送信される音声・テキスト等：上記2・3のとおり
  • サブスクリプション・アプリ内課金の購入状況：Apple を通じて処理
  • サブスクリプションの取引ID（App Store が発行する識別番号）：契約の確認と毎月の利用量の管理のため、当方のサーバーに送信
  • 追加ブースター（30日間）・お試しパックの購入の取引ID：購入内容の確認（Apple への照会）と、反映済みかどうかの管理のため、当方のサーバーに送信
  • お試しパックの財布ID（最初に購入したお試しパックの取引ID）：お試しパックの残りの管理と、機種変更・再インストール時の引き継ぎのため、端末の Keychain（iCloud キーチェーンによる同期を含みます）と当方のサーバーに保存
  • メールでお問い合わせいただいた場合：その内容（お問い合わせ対応に利用）
  • アプリの「フィードバック」（ご意見）機能で送信した場合：コメントとアプリのバージョン等の最小限の情報。文字起こし・整形結果は送信されません（下記9のとおり。運営者への通知には内容を含めません）

本アプリの利用にあたり、当方へのアカウント登録は不要であり、当方は氏名・連絡先等によって利用者を特定する情報を収集しません。

利用目的：取得・送信される情報は、(1) 音声の文字起こし・整形機能の提供、(2) クラウドAIによる整形の実行、(3) サブスクリプションおよびアプリ内課金（追加ブースター（30日間）・お試しパック）の提供・管理（残りの管理・機種変更時の引き継ぎを含みます）、(4) お問い合わせ対応、(5) フィードバックを運営者が確認し、本アプリおよびAI機能の改善の参考とすること、のために利用し、これらの範囲を超えて利用しません。

録音は利用者の責任において行われます。会議・対面の会話など、第三者を録音する場合は、あらかじめその方の同意を得てください。

7. サブスクリプション・アプリ内課金

有料プラン（Pro・月額）と、アプリ内で購入できる「追加ブースター（30日間）」「お試しパック」は、Apple の App Store（StoreKit）を通じて提供されます。料金の支払い、自動更新、解約は、Apple アカウントの設定に従います。価格・更新条件はアプリ内に表示します。当方はクレジットカード番号等の決済情報を取得しません。

契約の確認のため、本アプリはサブスクリプションの取引ID（App Store が発行する識別番号）を当方のサーバーに送信し、当方は Apple の App Store Server API を通じて契約が有効であることを確認します。あわせて、毎月の利用上限の管理のため、取引IDごとの利用回数・利用時間を当方のサーバーに記録します。取引IDから氏名・連絡先等は分かりません。

追加ブースター（30日間）：購入を反映するため、本アプリは購入の取引IDを当方のサーバーに送信し、当方は Apple の App Store Server API を通じて、購入の内容（商品・購入日時・返金の有無等）を照会します。照会した取引IDは、同じ購入を二重に反映しないために、サブスクリプションの取引IDと結び付けて当方のサーバーに記録します。有効期間（購入から30日間）と引き上げた上限は、サブスクリプションの取引IDごとの利用量とあわせて管理します。

お試しパック：お試しパックの残りは、最初に購入したお試しパックの取引ID（以下「パックの財布ID」）ごとに管理します。本アプリは、購入のたびに取引IDを当方のサーバーに送信し、当方は Apple の App Store Server API を通じて購入の内容を照会したうえで、パックの財布IDに残り（音声入力の時間・AI の回数）を加えます。当方のサーバーには、パックの財布ID、照会した取引ID、残り、利用量、月ごとの購入数を記録します。あわせて、残りの管理と機種変更・再インストール時の引き継ぎのため、パックの財布IDを端末の Keychain に保存します。iCloud キーチェーンをオンにしている場合、パックの財布IDは Apple の iCloud キーチェーンの仕組みで同じ Apple アカウントの端末に同期されます（当方は iCloud の内容を取得しません）。iOS 17 で iCloud キーチェーンをオフにしている場合など、機種変更や再インストールの後に残りを引き継げないことがあります。パックの財布IDから氏名・連絡先等は分かりません。

8. 第三者サービス・トラッキング

クラウドAI機能では外部の生成AIサービス（Google・Groq, Inc. 等）を利用します。各サービスの取り扱いは、各社のプライバシーポリシーに従います。当方は、広告目的の追跡（トラッキング）や広告識別子の利用を行いません。

9. データの保存・削除・エクスポート・安全管理

端末内のデータは、利用者がアプリ内で削除・書き出し（エクスポート）できます。本アプリを削除すると、端末内に保存されたデータは削除されます。ただし、お試しパックの財布IDは、残りを引き継ぐために Keychain に保存しているため、本アプリを削除しても端末や iCloud キーチェーンに残る場合があります。

安全管理措置：録音・文字起こし・整形結果などのコンテンツは、原則として利用者の端末内に保存され、当方のサーバーには保管しません。クラウド機能利用時の通信は暗号化（HTTPS）され、中継サーバーは送受信内容を保存・記録しません。一方、サブスクリプション・アプリ内課金の確認・利用上限の管理に必要な情報（取引ID・お試しパックの財布ID・利用回数・利用時間・お試しパックの残りと月ごとの購入数）と、フィードバックの内容は、運営に必要な範囲で当方のサーバー（Cloudflare）に保存します。フィードバックが届いたことの運営者への通知には外部メッセージングサービスを利用しますが、通知には内容を含めません。

保存先の国：当方のサーバーは、Cloudflare, Inc.（米国）が提供するクラウドサービスです。データは世界各地のデータセンターに分散して保存・処理される仕組みのため、保存されるサーバーの所在国を特定できません。

フィードバック機能：アプリの「フィードバック」機能では、コメントとアプリのバージョン等の最小限の情報のみを当方のサーバーに保存します。文字起こし・整形結果などの記録の内容は送信・保存しません。コメントには、患者さんの氏名など、個人を特定できる情報を書かないでください。フィードバックは運営者が確認し、本アプリおよびAI機能の改善の参考にします。外部のAIサービスに送信したり、AIの学習に利用したりすることはありません。保存期間は90日間で、その後は自動的に削除します。運営者への通知には外部のサービスを利用しますが、通知には送信内容を含めず、フィードバックが届いたことのみを知らせます。
